# Countermark demo — screen first, VO later

**Length target:** 1–3 minutes  
**Method:** Record silent (or ambient) screen capture of the happy path, then lay a voiceover track in iMovie / CapCut / QuickTime.

## Before you hit record

- App open at `http://localhost:3002` (or Railway URL if live)
- Hard refresh; **Reset** if needed so intake is empty
- Close unrelated tabs; hide `.env` / keys / Discord
- Optional: bump display zoom so text reads on phone/laptop playback

## Screen pass (clicks only — no need to talk yet)

| Time (approx) | Do this on screen |
|---------------|-------------------|
| 0:00–0:10 | Show landing: **Countermark** header, In-memory badge, empty intake |
| 0:10–0:25 | Click **Quick paste sample** (or Try sample). Show paste box + dispute box fill |
| 0:25–0:35 | Toggle one pill (e.g. Sent from no-reply) if not already on |
| 0:35–0:50 | Click **Analyze dispute**. Leave camera on amber **Analyze** progress + status line until results appear |
| 0:50–1:20 | Scroll review card: diagnosis → **To** badge → subject → draft |
| 1:20–1:35 | Scroll to **Helpful links** (subscription / consumer links) |
| 1:35–1:50 | Click **Copy to Clipboard** — show **Copied!** |
| 1:50–2:10 | Optional: click **Send via Email** if Mail opens cleanly on your machine; otherwise stop after Copy |
| 2:10–2:20 | Brief pause on review card / disclaimer — end |

**Optional second take (30s):** Upload `public/samples/ghost-renewal-sample.pdf` → watch extract fill paste box → Analyze once. Use only if you have time.

## Voiceover script (record after; match cuts loosely)

> Countermark helps when a bill or renewal lands from a no-reply address and there’s no obvious place to push back.  
>  
> Here I’m loading our Ghost SaaS sample — the unfair charge text and, in my own words, why I’m disputing it.  
>  
> I hit Analyze. The app diagnoses the merchant and amount, suggests a To address with an honest confidence badge, and drafts a short dispute email I can edit.  
>  
> It also surfaces category-matched consumer and ombudsman links — not legal advice, just where to escalate next.  
>  
> Finally I copy the draft — or open it in my own mail client. Countermark never sends email for me. I stay in control.  
>  
> That’s the proof of concept: paste or upload, understand the problem, send the dispute yourself.

## Export tips

- 1080p, horizontal; upload to YouTube (unlisted) or Streamable — link must open without login  
- Title e.g. `Countermark – Build With AI Basics demo`  
- Paste the URL into Devpost submission video field
