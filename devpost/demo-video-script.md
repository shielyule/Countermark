# Countermark demo — screen first, VO later

**Length target:** 1–3 minutes (aim ~2:00)  
**Live URL:** https://countermark-production.up.railway.app/  
**Method:** Record silent screen capture first, then lay voiceover in iMovie / CapCut / QuickTime.

## Before you hit record

- Prefer **Railway** in Safari or Chrome (not Cursor’s browser) so mailto looks real
- Hard refresh; **Reset** if intake isn’t empty
- Close unrelated tabs; hide keys / Discord / personal email
- Optional: slight zoom so text reads on phone playback

## Screen pass (clicks only — no need to talk yet)

| Time (approx) | Do this on screen |
|---------------|-------------------|
| 0:00–0:12 | Landing: cream background, shield logo, **Countermark**, In-memory badge |
| 0:12–0:28 | **Quick paste sample** (or upload `email-energy-final-adjustment.pdf` / gym letter for variety) |
| 0:28–0:40 | Show dispute box + one pill (e.g. no-reply / cancelled) |
| 0:40–1:05 | **Analyze dispute** — keep frame on amber progress until Review appears (honest wait) |
| 1:05–1:20 | Diagnosis + **To** confidence badge (inferred / verified) |
| 1:20–1:40 | **Escalation ladder** — click Level 1 → 2 → 3; draft text changes |
| 1:40–1:55 | Point at **Advice** box + **Evidence checklist** (missing attach lines) |
| 1:55–2:10 | **Portal mode** — Copy Chunk 1 (short); flash char count |
| 2:10–2:25 | **Send via Email** — show one-line status under buttons; and/or **Copy full email** → Copied! |
| 2:25–2:35 | Brief scroll past **Helpful links** + disclaimer — end |

**Optional B-roll (15–20s):** Upload a second sample PDF (gym or water) → extract fills paste box → stop before full analyze if time is tight.

## Voiceover script (record after; match cuts loosely)

> Corporate billing counts on you giving up. Countermark is counter-offensive infrastructure for consumers — paste or upload a notice, and get a dispute you send yourself.  
>  
> Here’s our sample ghost renewal. I add why I’m disputing it, then hit Analyze.  
>  
> While Gemini works, you stay on this page — no black-box spinner.  
>  
> Results: diagnosis, a To address with an honest confidence badge, and a draft I can escalate. Watch the tone dial — polite, assertive, or regulatory — without rewriting from scratch.  
>  
> The advice box and evidence checklist tell me what to attach — cancellation proof, statements — so the package is ironclad.  
>  
> Portal mode solves tight web forms with short, full, and formal paste chunks. Send via Email opens my mail client; the full draft is also on the clipboard. Countermark never sends for me.  
>  
> Zero retention — session dies on reload. That’s the proof of concept.

## Shorter VO (if you need under 90 seconds)

> Countermark turns a no-reply bill into a dispute draft you send yourself. Paste or upload, analyze, pick your tone, check the evidence list, copy a portal chunk or open mail. You stay in control — we don’t send email and we don’t keep your data.
